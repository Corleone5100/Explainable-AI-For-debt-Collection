9. REMAINING WEAKNESSES AND RECOMMENDATIONS
================================================================================

  ISSUE 1: MEDIUM RISK STILL NEGATIVE (Main Remaining Challenge)
    Problem: -Rs. 1.11M loss on Medium risk (15.8% resolved, 63.6% correct)
    Root Cause: Agent uses No Action 25.5% of the time (zero revenue), and
      doesn't consistently use the productive actions (SMS or Field Visit)
      that would generate recovery revenue.
    Impact: If Medium risk could break even, total reward would increase by
      Rs. 1.11M to Rs. 14.23M.
    Fix: Consider reducing the No Action penalty threshold for Medium risk,
      or adding a medium-specific reward bonus for using SMS or Field Visit.
      Alternatively, the Medium risk category may need a different optimal
      action distribution than what the current reward function encourages.

  ISSUE 2: LOW RISK STILL SLIGHTLY NEGATIVE
    Problem: -Rs. 542K loss on Low risk (76.5% resolved, 60.5% correct)
    Mitigation: Legal eliminated (0%), Field Visit reduced to 13.5%
    Status: Much improved from original -Rs. 1.3M. The Hybrid policy
      reduces the loss further to -Rs. 487K by using SMS 83.4% of the time.
    Remaining gap: The PPO uses No Action 39.5% (zero revenue). The fix
      used for Medium risk would also help Low risk.

  ISSUE 3: ABLATION REDUCED SETS ALL NEGATIVE
    Problem: All reduced feature set configs lose Rs. 31-32M
    Interpretation: This may be because the reduced configs are trained
      with fewer timesteps per config, or because they genuinely lack the
      information needed for profitable decisions. The full 150-feature
      config achieves +Rs. 6.99M, confirming the full model works.
    Recommendation: Use the full feature set for production.

  ISSUE 4: REPRODUCIBILITY
    Problem: Different evaluation runs show slightly different numbers due
      to stochastic recovery probabilities.
    Fix: Already addressed — changed np.random to self.np_random in
      debt_env.py step() function for proper seeding.
